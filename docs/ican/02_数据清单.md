## 2.2 处理流程（通用）
1. **采集**：系统内数据由人工操作自然产生；历史数据走 Excel 导入（列名模板固定）。
2. **清洗**：去空格/全半角、日期统一、单位换算（瓶↔箱，箱规取 D02）、去重（同客户+日期+金额）。
3. **对齐**：以「单号」为主键串联采购单→入库流水→应付→对账；批发单→出库流水→应收→收款登记。时间统一为 Asia/Shanghai。
4. **脱敏**：对外演示一律用「演示酒业」数据；联系人电话、银行账号、凭证号不进入演示库；真实德鉴数据不进 git 仓库（`PLAN.md` §3）。
5. **完备性评估**：每个数据集按「关键字段非空率」计算，公式：非空率 = 关键字段非空记录数 ÷ 总记录数。阈值（例如 ≥95% 才进入测算）为「演示假设」。
6. **缺失补齐**：优先人工补录 → 其次规则推导（如从对账单反推）→ 补不了的字段不参与测算，并在建议中显示“数据不足”。
