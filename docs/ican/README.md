# 德鉴 × AI 运营效能提升方案（iCAN「精创杯」AI 智能决策挑战赛）

命题：「AI 赋能·效能跃升」——基于 AI 的企业运营效能提升方案（见 `docs/REQUIREMENT.docx`）。
研究对象：德鉴（贵州酱香白酒，多品牌 To B 经营）。系统载体：本仓库（IOE 二开）——`tenancy` 多租户、`b2b` To B 交易、`ai_assist` AI 建议。

## 标注规则（必读）
- **「演示假设」**：凡没有真实可追溯来源的数字，一律带此标签。它们是答辩前要被驻厂跟岗/台账替换的初值，**不是德鉴的事实**。
- **【待核实】**：关于德鉴的定性事实，仓库与现有文档里没有出处的，带此标签，路演前须向企业确认。
- 已有出处的事实，在句末注明来源（文件路径）。
- 本文档不编造成效结果；第 4 篇只给**测算方法与公式**，结果由系统回测/仿真产出后再填。

## 产品铁律（贯穿全部文档）
AI 只做重复活：算数、对表、筛异常、起草建议/草稿。**人做决定和执行：审批、入库、发货、付款、对账确认。**
代码落点：`b2b/services.py` 中所有状态流转函数都要求已登录、启用、且有对应权限的真人 `actor`，视图只接受 POST；AI 唯一的写入口是 `create_purchase_draft`（只生成 `DRAFT`）。测试 `b2b/tests/test_b2b.py` 守住这一点。系统不接入任何支付（收付款为线下完成后的人工登记）。
