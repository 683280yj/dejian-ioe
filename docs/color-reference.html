03 / AI PLAYBOOK

采购端与销售端的四张决策卡

每张卡都明确输入、模型思路、输出和人工边界，便于从“看报表”转向“做决策”。
⌁

需求预估 · 从历史到场景

输入销量、节假日、活动、渠道库存与复购率。以季节性分解 + LightGBM/Prophet 预测基线，再叠加活动 uplift。

预测需求 = 基线 × 季节系数 + 活动增量 × 渠道弹性
▦

订货与库存 · 从箱到吨

将 SKU 需求拆成基酒、包材与加工批次，结合在途、交期、MOQ 和安全库存生成建议采购量。

建议订货 = 预测需求 + 安全库存 − 可售库存 − 在途库存
↗

定价与促销 · 从统一价到分市场

按低端流通、中端标准、高端礼盒与渠道组合，估计价格弹性和活动增量，约束毛利底线后给出价格带。

最优价 = argmax(销量 × 单价 − 投放费 − 返利)
◎

滞留控制 · 从预警到动作

用库龄、周转、动销率、退货和活动响应识别慢动 SKU，触发换货、组合促销、减产或暂停采购。

滞留分 = 0.35×库龄 + 0.30×周转偏离 + 0.20×动销下降 + 0.15×退货
⌂

渠道投放 · 从撒网到分层

基于客户 RFM、复购概率与市场潜力，分配私域、团购、经销商与礼赠预算，持续 A/B 复盘。

投放优先级 = 预计增量毛利 × 转化概率 ÷ 获客成本
✓

人工边界 · AI 给建议，人拍板

采购负责人确认供应商与合同，销售负责人确认价格和活动，财务校验毛利与预算，所有修改保留理由。

建议 → 解释 → 审批 → 执行 → 结果回写

06 / DECISION PRINCIPLES

每个 AI 建议背后的经济学与管理学原理

模型负责计算，原理负责解释边界。切换分类查看这些原理如何进入采购与销售决策。
经济学 · 需求

价格弹性与三级价格歧视

不同市场对价格变化的敏感度不同。AI 按流通、团购、礼赠分别估计弹性，在毛利底线内给出差异化价格带。

ε = 需求量变动% ÷ 价格变动%
经济学 · 库存

报童模型与边际损失

订多会占用资金并形成滞留，订少会产生缺货损失。最优库存来自缺货成本与剩余成本的平衡。

临界分位 = 缺货成本 ÷ (缺货成本 + 滞留成本)
经济学 · 资金

机会成本与现金转换周期

压在库存中的资金不能用于市场投放或其他 SKU。AI 同时考察库存收益、融资成本和回款周期。

占资成本 = 平均库存 × 资金成本率 × 持有时间
经济学 · 投放

边际分析与增量 ROI

促销预算继续增加，新增销量通常递减。预算应投到最后一元仍能产生正增量毛利的位置。

继续投放条件：边际毛利 ≥ 边际投放成本
管理学 · 协同

S&OP 销售与运营计划

销售预测、采购能力、加工产能和资金预算在同一节奏下审议，防止销售冲量与采购积压相互脱节。

需求计划 → 供应计划 → 财务校验 → 管理层批准
管理学 · 分类

ABC × XYZ 库存管理

ABC 看价值贡献，XYZ 看需求波动。高价值稳定品强调服务水平，高波动品强调小批量与高频复盘。

价值贡献 × 需求波动 → 补货策略
管理学 · 流程

PDCA 与滚动预测

建议不是一次性答案。计划、执行、检查偏差、修正参数，形成周度滚动的模型与经营闭环。

Plan → Do → Check → Act
管理学 · 风险

牛鞭效应与延迟差异化

促销预测若层层放大，会导致采购过量。先保留通用基酒，接近销售时再决定包装与产品档位，可降低结构性积压。

共用原料池 + 延迟包装 + 小批量释放
管理学 · 激励

平衡计分卡与目标一致

只考核销售额会鼓励压货。应同时考核毛利、周转、回款、复购和预测准确率，让采购与销售共享结果。

销售额 + 毛利 + 周转 + 回款 + 复购
P5 / CURRENT OPERATIONS

优化前：采购与销售依赖人工经验

先还原企业原有操作，才能明确 AI 应介入哪里、保留哪些人工审批。

采购端原有流程

人工主导
经验预估参考往年销量、节庆和经销商口头反馈
集中下单Excel 汇总后一次性确定数量与供应商
到货入库人工登记批次、数量和到货日期
库存盘点月底汇总，发现积压后再安排消化
主要风险：预测颗粒度粗、订单释放过早、在途与可售库存不同步、滞留发现偏晚。

销售端原有流程

人工主导
人工定价沿用历史价格和经销政策，缺少弹性测算
市场投放预算按经验分配，难区分增量贡献
促销活动节前统一促销，不同客群使用相近方案
订单销售成交后汇总，结果较少回写采购计划
主要风险：价格与市场敏感度脱节、投放撒网、促销挤压毛利、销售与采购缺少闭环。
